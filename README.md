This entry is a program that writes one image to the output directory, crafting the best-looking food picture for the judge: a gourmet cheeseburger with melted cheddar oozing down the sides, a glossy toasted brioche bun, a juicy beef patty, crisp lettuce and ripe tomato, in warm golden light against a dark background.

## Run It

To run the program locally and generate the food picture into an `out` directory:

```bash
MAKEFUN_OUTPUT_DIR=out node main.ts
```
